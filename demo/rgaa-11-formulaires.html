Démo RGAA 11 – Formulaires

Cette page rassemble des champs et boutons conformes et non conformes à la thématique 11 du RGAA. Chaque carte indique le résultat attendu dans le panneau du bookmarklet.

Lancer RGAA 11 – Formulaires (ou utilisez votre favori). Survolez les champs, ou parcourez-les au clavier avec Tab : le détail suit le focus. Échap arrête le bookmarklet.

11.2 et 11.9 L’intitulé visible est-il dans le nom accessible ?

Quand le nom vient de aria-label ou aria-labelledby, il doit contenir l’intitulé visible.

Conformearia-label qui reprend le label

Attendu : ✓ nom « Nom de famille » (aria-label), aucun constat.

Non conformearia-label sans le label

Attendu : × « Le nom ne contient pas l’intitulé visible « Code postal » (11.2.5) ».

ConformeBoutons avec intitulé

Attendu : ✓ « Envoyer » (contenu), « Valider » (value), « Fermer » (aria-label).

Non conformearia-label différent du texte

Attendu : × « Le nom ne contient pas l’intitulé visible « Envoyer » (11.9.2) ».

Non conformeBouton icône sans intitulé

Attendu : × « Bouton sans intitulé » dans la liste et le compteur.

ConformeBouton image

Attendu : ✓ intitulé « Lancer la recherche » (alt).

11.10 Contrôle de saisie : obligatoire et erreurs

Conformerequired + indication visible

Attendu : « Obligatoire : Oui (required) » et ! « Vérifier que le caractère obligatoire est aussi indiqué visuellement (11.10) » : ici, c’est le cas.

Non conformeObligatoire non indiqué visuellement

Attendu : « Obligatoire : Oui (aria-required) » et le même constat ! : ici, rien n’est visible.

ConformeErreur reliée au champ

5 chiffres, par exemple 75011.

Erreur : le code postal doit contenir 5 chiffres.

Attendu : description = aide + erreur (aria-describedby), « Invalide : true (aria-invalid) ».

Non conformearia-describedby vers un id absent

12 caractères minimum.

Attendu : × « aria-describedby : id introuvable (c-mdp-regles) ».

11.13 Finalité des champs : autocomplete

Un champ qui concerne l’utilisateur doit avoir un autocomplete avec une valeur de la liste WCAG.

Attendu : « Autocomplete : shipping postal-code » et « work tel » (autocomplete).

Non conformeValeur inventée

Attendu : × « code-postal : « code-postal » n’est pas une valeur autorisée », compté dans « autocomplete invalide ».
